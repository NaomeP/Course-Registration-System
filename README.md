# Course Registration System

A full-stack Course Registration System developed using Spring Boot, MySQL, HTML, CSS, and JavaScript.

## Features

- View available courses
- Register for a course
- View enrolled students
- Store course registration details in MySQL
- REST APIs using Spring Boot

## Technologies Used

- Java
- Spring Boot
- MySQL
- HTML
- CSS
- JavaScript
- Maven

## Project Flow

Frontend → Spring Boot REST API → MySQL Database

## API Endpoints

- GET `/courses` - View available courses
- GET `/courses/enrolled` - View enrolled students
- POST `/courses/register` - Register for a course
